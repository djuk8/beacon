# Appendix C. Notation
 n0 = k*zd#/d  campaign center;  zd# primorial;  d even squarefree
 lam = ln n0;  D decimal digits;  L = ln lam;  z = zd/lam
 j offset; candidates n0 + j;  jf window edge = (m/2) lam
 merit m = gap / ln p1;  u = 1 + ln(m/2)/L (identity coordinate)
 survivor: j with no factor <= Q in n0 + j;  channel: j = s*q,
   s even d-smooth, q = 1 or prime > zd;  truncation s <= m/2
 c_d(s) per-channel class survival;  w_d(s) = c_d(s)/s (mass;
   SUM = 1);  F_d(m) filling = reachable mass
 Theta(zd,Q) deep thinning;  beta = e^gamma ln Q / lam
 E = beta * E[S] luck exponent; windows geometric, mean e^E
 sigma = E/m structural discount (unstructured sigma = 1 exactly)
 shelf: the record locus in (u, m, L);  supply wall: ln(#k) < E+1
 ring/ladder: nested windows, ks advance while prime-free;
   ladder factor dE/(1-e^-dE) tests-per-window
 fence: first prime each side;  born verified: interior
   composite-certified at find time;  GEC: Gerbicz error check
